# 🏫 PCIU Room Management System

Smart room availability and scheduling system for Port City International University.

## ✨ Features

- 🔍 **Real-time Room Availability** - Check free rooms by day and time
- 👤 **CR Panel** - Class Representatives can manage schedules
- 🔐 **Token-based Authentication** - Secure login system
- 🏷️ **Room Ownership Tracking** - See which departments use which rooms
- 📊 **Admin Dashboard** - Complete system management
- 📱 **Responsive Design** - Works on all devices

## 🚀 Tech Stack

- **Frontend**: Next.js 14 + TypeScript
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL (Supabase)
- **Authentication**: JWT
- **Deployment**: Vercel
